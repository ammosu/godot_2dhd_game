# Wanderlight: Moon Shard

這是一個以 Godot 4.7 建立的原創 HD-2D 技術基線，參考
[SimpleHD2D](https://github.com/GSansigolo/SimpleHD2D) 的核心方向：把清晰的 2D 角色放進有光影、透視與景深的 3D 世界。

目前是一個可以從頭玩完序章〈熄滅的月燈〉的 HD-2D JRPG vertical slice：

- 原創四方向主角行走圖集與相機相對移動；同角色外觀的獨立戰鬥姿勢圖集
- 可平滑旋轉、縮放並追蹤玩家的透視相機
- 約 35×30 世界單位的暮光村與北境遺跡探索區；村莊含八棟房屋、街區、水域，以及碰撞、燈光、薄霧與景深
- 村莊與遺跡的木箱、陶罐、水晶、木圍欄、路燈及樹幹具有實體碰撞；低矮草花可穿行。
- 八棟房屋可從門口互動進入，參觀基本住宅格局：床鋪、桌椅、書架、窗戶與壁爐；室內支援鏡頭旋轉、碰撞、小地圖與存讀檔
- 房屋依主題搭配植物、月相、地圖或幾何紋樣壁掛，以及書冊、捲軸與陶器桌面陳設；仍共用基礎格局，窗邊花台與陶器展示架具有碰撞，保留中央入口通道；裝飾沒有搜刮互動
- 村莊、遺跡與屋內各有原創合成環境音，隨場景淡出淡入、戰鬥時停止，共用音量與靜音控制（聽感混音仍待驗收）
- CC0 像素場景裝飾／HUD、最近鄰取樣與輕量色調／暗角 shader
- 長老、守門人與村童的狀態式對話、主線任務、遺跡線索與完成獎勵
- 與村民交談時，鏡頭自動平滑拉近、降低俯角並轉向雙人側面構圖；結束後恢復原本探索角度與距離。
- 主線角色以金黃色「！」、可選內容以青藍色「！」標示，並依進度自動顯示或消失
- 右側即時小地圖會顯示區域地形、玩家朝向、出口及目前任務目標；按 G 或點右側「地圖」放大後，點擊重要地點圖示（任務人物、出口、互動事件）會自動尋路前往；放大圖示方便點選，滑鼠停留顯示地點名稱。一般住宅只保留建築輪廓，不標名稱或可點選圖示。小地圖僅顯示位置、目標及青綠色路徑，不接受目的地點選。按移動鍵／操作搖桿立即取消，對話、戰鬥或換圖時停止；無路可達或途中受阻會提示。抵達後沿用原本互動方式。
- 會隨劇情從微弱轉為明亮的中央月燈，以及可恢復 HP／MP 的遺跡月泉
- 3 對 3 動作戰鬥：直接操控隊員移動、攻擊、施放技能與閃避，另外兩名同伴由 AI 助戰。
- 敵人會追擊並顯示地面預警；攻擊有前搖、範圍判定與受擊打斷，技能起手消耗 MP，命中時結算傷害。
- 探索腳步依泥地／石路／木地板使用原創交替音色，依實際移動距離觸發；撞牆、對話或停下時不播放。
- 原創村莊／遺跡／戰鬥背景音樂循環與八種短音效；切換時淡入淡出，勝敗提示期間背景樂退下，音量偏好可保存
- JSON 存檔／讀檔，保存地圖、位置、任務、旗標、道具、HP 與 MP
- 可視化裝備畫面：中央角色、左右武器／防具欄、四方向行走與七種戰鬥姿勢預覽；試穿顯示攻防差異，確認後同步到探索、戰鬥與存檔

## 山區野外地圖

從東行舊道北行進入螢光森林，再穿過森林北口，可依序探索 **苔階山徑 → 風切峽道 → 月冠高地**，並沿原路返回。山路有連續爬坡、折返彎、層疊崖壁、草木與遠山；三區山腳到山頂分別約有 7.2、9、5.8 世界單位的落差，月冠高地盡頭有可調查的眺望點。這些區域目前以步行探索為主。

按 G 點出口圖示可沿山路自動上下山；崖邊矮牆防止跌落。存讀檔保留所在山區與高度，沿用原存檔格式。地形、碰撞、地圖與自動行走共用 `scripts/gameplay/mountain_maps.gd` 的路線資料，重用專案既有苔岩、砂岩、碎石與草地素材，沒有新增第三方資產。

快速預覽：`godot --path . -- --mountain-preview`，從苔階山徑山腳開始；預覽不寫入正常自動存檔。

## 星灣城與風丘商道

從暮光村東口走到東行舊道，再沿東側道路進入風丘商道；順著彎路北行即可抵達星灣城，全程可步行往返，不受北門主線封印限制。

星灣城約 78×76 世界單位，採不規則城牆外緣、五條彎曲街道與相連巷道，配置 26 棟住宅外觀、月帆市集、舊城巷、工坊街、水岸池畔與鐘樓庭。四位居民會散步並可交談；市集茶棚可恢復生命／魔力，城門路牌與鐘樓石誌提供指引。26 棟城內房屋皆可貼近門口並面向門時自動進入，各有固定地址與屋主。室內分為旅舍、住家、商舖、書房、工坊、藥房六種格局，包含雙床客房、家庭隔間、貨物後間、狹長閱讀區、工作台與草藥育苗區；不同房型有不同尺寸與缺角輪廓，並提供對話、陳設調查和室內存讀檔。離開時返回原本房屋門外；商舖目前可參觀，尚無交易系統。按 G 查看區域地圖，南門可返回商道。原有八棟暮光村住宅仍可進入。

新地區沿用目前存檔格式，保存地圖與所在位置；地形、街道與大小地圖共用 `scripts/gameplay/starbay.gd` 的幾何資料。沒有新增第三方素材。

快速預覽：`godot --path . -- --city-house-preview`（南門旅舍室內）、`godot --path . -- --city-preview`（星灣城南門）或 `godot --path . -- --caravan-preview`（風丘商道南端）；預覽不寫入正常自動存檔。

星灣城另有 7 棟町屋風格外觀：車伕之家、溪風茶室、石巷客舍、守鐘人之家、匠人之家、岸邊旅店、南岸茶室。採長向灰瓦屋脊、弧形深簷、木格窗、暖簾、紙燈籠與淺木廊，與原有建築混合配置；沿用各屋的室內、地址和進出動畫。模型由程式原創生成，重用現有材質。`godot --path . -- --japanese-preview` 可從南門店舖街開始試看。

## 遊玩流程

完整故事對應操作、戰鬥準備與重試流程見 [序章遊玩指南](docs/GAMEPLAY_GUIDE.md)。左上任務提示會依目前地圖切換下一步：離開住宅、穿過北門、挑戰守衛，或帶碎片從南門回村。

1. 調查暮光村中央逐漸熄滅的月燈，並向村童露米、守門人諾亞了解村莊近況。
2. 與廣場左側的艾爾長老交談，接受尋找「月光碎片」的任務。
3. 取得月印、開啟北方月紋雙扇門後，直接穿過門框前往北境遺跡；途中可閱讀風化石碑並在月泉恢復 HP／MP。
4. 與諾亞、長老一起接受遺跡試煉。選技能、點敵方卡片選目標、確認施放；擊敗所有敵人才能獲勝。
5. 直接穿過南方門扉返回村莊，將月光碎片交給長老並點亮月燈。

序章完成後仍可探索村莊、遺跡及八棟住宅。貼近房屋門口並面向門時，不必按鍵就會自動開門；角色會保持面向房門向外退讓，等木門向外打開後，再走到門口進入室內（期間暫停操作）；貼近室內南側微光出口並面向門時，角色會面向房門，待木門向內開啟後返回該棟房屋原門口（期間暫停操作）；轉動鏡頭看得到門時，也能看到開門動畫。進出屋開門時持續面向房門，抵達後朝向通過門口的行進方向。近鏡頭的牆面會自動隱藏，但仍保留碰撞；Q／E 可換角度參觀。室內採正交鏡頭，人物在房間前後保持相同比例；住戶直立顯示，各自依實際圖片對齊腳底，避免穿入地板或家具。八棟住宅各有一位可按 Space 交談的住戶，對話依房屋主題而異；八位住戶各有原創職業造型：織工、園丁、觀月人、陶匠、裁縫、旅人、藥師與藏書人。每位角色具備八方向、每方向四個姿勢畫格；轉動鏡頭會看到對應側面或背面，交談時會轉向玩家。村莊街道固定由園丁芙蘿、織工米菈與藏書人歐文巡遊，各自沿原路線散步並播放對應方向的踏步動畫。靠近後按 Space／Enter 可聽見各自的日常短對話，交談時停步，結束後恢復巡遊。書架可閱讀，床鋪目前僅供參觀，不會恢復數值。遺跡石碑上的環形紋章會在結尾留下後續故事線索。

## 操作

- `WASD`／方向鍵：移動
- `Space`／`Enter`：互動、繼續對話
- `Q`／`E`：旋轉鏡頭
- `R`／`F`：縮放鏡頭
- `F5`：儲存遊戲
- `F9`：讀取遊戲
- `G`：開啟／關閉目前區域的大地圖（北方朝上）；也可點右側「地圖」。`Esc` 或「關閉」返回遊戲。顯示玩家、出口、主線／可選目標與出口方向說明；開啟時鎖定移動及互動，對話、戰鬥、換裝與過場期間不能開啟。
- `I`：開啟／關閉裝備選單；點選或以 Tab／方向鍵與 Enter 選擇試穿，再按「確認穿戴」。`Esc` 關閉並取消未確認的試穿；「還原試穿」返回目前穿戴
- `M`：靜音／恢復；`-`／`=`：降低／提高音量（每次 10%）。探索、對話與戰鬥均可使用，畫面會顯示目前音量；偏好另存於 `user://audio_preferences.cfg`，不影響劇情存檔。
- 瀏覽器首次開啟時，先點一下遊戲畫面啟動聲音。`default_bus_layout.tres` 在啟動前配置 Master／SFX／Music／Ambience，避免 Web 執行中增設匯流排造成無聲。
- 戰鬥：`WASD`／方向鍵移動、`J` 普攻（可按住）、`K` 技能、`Space` 閃避、`Tab` 換人、`H` 藥水、`Esc` 暫停、`B` 切換自動戰鬥；也可點畫面按鈕。

守衛戰直接在北境遺跡原地進行，不切換場景或另開戰鬥畫面。沿用探索鏡頭並平滑拉遠，可用 Q/E 旋轉、R/F 縮放。石柱、牆壁與箱子會阻擋移動與攻擊；敵人沿碰撞資料建立的路徑繞行。試煉範圍以地面封印線標示。紅色「危險」圈是敵人鎖定的攻擊區域，離開即可躲避；命中可打斷對方蓄力。閃避冷卻 1.1 秒、無敵 0.30 秒，不耗 MP。角色間會推開，且不能離開場地邊界。換人不重置冷卻；操控角色倒下時自動切換存活隊員，全隊倒下才敗北。

每次守衛戰開始前會顯示「戰鬥準備」彈窗，確認前敵我暫停。可選開場自動戰鬥、自動使用技能（含同伴治療）、自動喝藥水及 HP ≤30%／50%／70% 的喝藥門檻，按「開始戰鬥」後生效。每場預設手動、技能開啟、喝藥關閉；設定只適用當場，不寫入存檔。Tab／方向鍵與 Enter 或滑鼠／觸控可操作列表。

戰鬥中按 B 或左側開關切換自動，也可在暫停時切換。自動追擊、繞路、普攻與閃避仍受碰撞與冷卻限制；開啟技能時長老優先治療並保留治療用 MP，諾亞在同伴受傷時守護。關閉自動技能後同伴不會耗 MP，仍可手動按 K 施放。啟用自動喝藥後，僅目前操控角色達到門檻且動作就緒時消耗共享庫存，每瓶最多恢復 35 HP；滿血、無庫存、暫停或戰鬥結束不喝藥。WASD／搖桿或手動攻擊、技能、閃避、喝藥會交回操作；Tab 只更換跟隨角色並保留自動。

旅人技能為月影斬（近距離範圍傷害）；諾亞為全隊守護（3 秒內受傷減半）；長老為霜星爆（鎖定 6 單位內最近敵人當下位置）。技能均消耗 5 MP、冷卻 3 秒。長老與術士的普攻也會瞄準敵人位置。未操控同伴自動接近與攻擊；啟用自動技能且長老有足夠 MP 時優先治療低血量同伴（6 MP、25 HP）。同伴 AI 不使用共享藥水。

HUD 以血條與數字顯示操控角色 HP，並顯示 MP、剩餘敵人、技能／閃避冷卻；敵我角色頭上顯示姓名與血條（友方綠色、敵方紅色），操控角色 HP 低於或等於 25% 時 HUD 血條轉紅，青色圈與箭頭標示操控角色。藥水恢復目前角色最多 35 HP，滿血、庫存不足或動作未結束時不扣除。暫停或視窗失去焦點會凍結戰鬥，按 Esc 或繼續按鈕恢復。敵方全倒下後自動收起戰鬥 HUD，在原地取得碎片並接續劇情；不重載地圖或要求按結果確認。

命中時附帶金色碎光、短暫受擊亮白、跳動後淡出的傷害數字與輕微鏡頭震動；月影斬追加藍白碎光及擴散地面光環。特效隨戰鬥暫停，結束後重置鏡頭偏移，同時最多保留 32 組特效。

本版諾亞與長老是試煉援軍，每場恢復初始 HP／MP，尚無永久隊伍編成；三位角色的裝備、旅人 HP／MP 與藥水由 GameState 保存。援軍換裝會更新村莊站姿及戰鬥外觀／攻防。旅人倒下但隊伍獲勝時以 1 HP 起身。戰鬥中途不存檔或更換裝備。諾亞與長老使用原創關鍵姿勢，並非完整逐格動畫；來源與提示詞見 `assets/generated/ALLY_COMBAT.md`。

挑戰前觸碰月泉，即使滿血也能閱讀戰鬥教學。全隊倒下會返回暮光村並恢復旅人 HP／MP，任務與北門保持可重試；已消耗的藥水不會補回。序章結束後可繼續探索，但尚不能前往古道另一端。

### 手機瀏覽器

GitHub Pages Web 版會在 Android／iOS 瀏覽器自動顯示觸控操作，行動版預設使用橫向畫面：

- 左下搖桿：移動
- 右下「互動」：調查、交談；對話中點一下畫面即可繼續
- 在場景空白處單指左右滑動：平滑旋轉鏡頭（已移除兩顆旋轉按鈕）。垂直滑動及輕微手抖不旋轉。
- 右上「存檔」／「讀檔」：保存或繼續進度
- 小地圖下方「地圖」：開啟目前區域的大地圖，點「關閉」返回
- 右上「裝備」：開啟武器／防具選單
- 戰鬥沿用左下搖桿；另一指可在空白處滑動轉鏡頭，也可同時點右下圓形按鈕出招。從技能、頭像、地圖或選單上起手不會旋轉。暫停、開啟設定、失焦、換圖或改變螢幕方向後，需重新按下才能開始新手勢。

原生 Android／iOS 版會鎖定為感應式橫向，可隨手機左右翻轉；PWA 匯出的方向偏好也預設為橫向。一般手機瀏覽器在直向時，點一下畫面會嘗試進入全螢幕並切換橫向；若瀏覽器不允許強制方向，畫面會繼續顯示旋轉提示。

桌面測試觸控介面時可加上 `--mobile-controls`：

```bash
godot --path . -- --mobile-controls
```

## 執行

用 Godot 4.7.x 開啟此資料夾後執行主場景，或在終端執行：

```bash
godot --path .
```

完整 playthrough smoke test：

```bash
godot --headless --path . -- --playthrough-test
```

通過時會輸出：`PLAYTHROUGH_TEST_PASS dialogue quest maps save battle`。

快速檢查地圖構圖時可使用 `-- --village-preview`、`-- --ruins-preview` 或 `-- --interior-preview` 跳過開場對話。

直接試玩裝備畫面：`godot --path . -- --equipment-preview`。

原版畫風的分層換裝測試：`godot --path . scenes/layered_equipment_lab.tscn`。
旅人、諾亞、長老各以五張共用圖層組合兩武器、兩防具與四個戰鬥姿勢，共 48 組；1／2／3 切換角色，E 拆層。
主遊戲加 `--layered-equipment` 可在裝備預覽及隊伍戰鬥使用已完成的四姿勢，
例如 `godot --path . -- --equipment-preview --layered-equipment`。

## 系統結構

旅人初始提供旅人短刃、月鋼彎刀、旅人長衣及月守披風，尚無商店或裝備掉落。四種搭配使用完整角色替換圖集，原衣物與武器不會殘留在新裝備底下；涵蓋四方向共 16 個行走畫格與七種戰鬥姿勢。月鋼彎刀具有獨立刀身、月牙護手及刀鞘，月守披風包含靛紫衣物、銀色肩甲與月石扣飾。探索顯示刀鞘，戰鬥顯示彎刀刀身。裝備畫面能單獨試穿武器、防具及檢查各姿勢，未確認前不改變遊戲角色或能力。素材與提示詞見 `assets/generated/equipment/README.md`。

隊伍裝備畫面可切換旅人、諾亞與長老。每人都有兩款專屬武器、兩款防具，可獨立組合（共 12 種角色搭配）：旅人的短刃／彎刀、長衣／披風；諾亞的守門長槍／曙光翼槍、守門甲衣／曙光鎧甲；長老的引燈木杖／星月法杖、長老法袍／星辰祭袍。確認僅套用目前角色；切換頁籤保留各自試穿，關閉選單會取消全部尚未確認的試穿。援軍只有村莊站姿與七種戰鬥姿勢，介面不提供不存在的行走動畫。

存檔 version 3 保存持有清單與三人穿戴；version 1／2 會保留旅人的既有裝備與攻防基線，補上援軍初始選項。version 3 不會重新贈送已失去的升級裝備；非法、錯欄或跨角色裝備回復相應角色的初始裝備。對話與戰鬥中不能更換裝備。

- `scripts/systems/game_state.gd`：任務、玩家數值、道具、裝備、地圖狀態及 JSON 存讀檔
- `scripts/systems/party_equipment.gd`：角色相容性、專屬裝備資料與基礎能力
- `scripts/gameplay/equipment_appearance.gd`／`equipment_actor.gd`：完整換裝圖集、裁切、接地、快取與村莊角色連動
- `scripts/ui/equipment_ui.gd`／`equipment_portrait.gd`：試穿、確認、能力比較與共用角色外觀
- `scripts/systems/game_audio.gd`／`game_music.gd`：音效池、音量偏好與背景樂場景切換；不擁有劇情狀態
- `scripts/ui/dialogue_ui.gd`：多段式對話與輸入鎖定
- `scripts/systems/action_battle.gd`：動作戰鬥模擬、空間命中、敵人與同伴 AI
- `scripts/gameplay/world_action_battle.gd`：原地戰鬥角色、場景碰撞、障礙物繞行、視線判定與清理
- `scripts/gameplay/combat_ground_ring.gd`：貼地攻擊預警與操控標記
- `scripts/ui/action_battle_ui.gd`：即時操作與透明 HUD，不建立獨立視埠
- `scripts/gameplay/interactable_3d.gd`：NPC、門扉與敵人的統一互動介面
- `scripts/gameplay/house_catalog.gd`：住宅固定 ID、名稱與原門口返回位置
- `scripts/gameplay/house_interior.gd`：可參觀室內、家具碰撞與牆面自動隱藏
- `scripts/world.gd`：村莊／遺跡／住宅地圖切換、事件配置及完整主線流程

室內沿用既有存檔欄位 `current_map`／`saved_position`，以 `house_01`～`house_08` 識別住宅；原 version 1 村莊／遺跡存檔會透過上述裝備遷移繼續使用。

目前桌面預設使用 Forward+，以呈現景深、進階光影與高品質 bloom；行動裝置預設使用 Mobile。若目標包含 Web／舊硬體，需另做 Compatibility 畫質配置，並停用不支援的景深效果。正式製作應建立低／中／高三組畫質設定。

## 為何沒有直接複製參考專案

截至本專案建立時，SimpleHD2D 倉庫沒有宣告 LICENSE；其中的角色圖也來自商業遊戲《Final Fantasy VI》。因此本專案只參考構成方式，沒有複製其程式碼或素材。程式與原始 SVG 佔位圖皆為本專案重新製作；後續引入的第三方像素素材則逐項記錄於 [THIRD_PARTY_ASSETS.md](THIRD_PARTY_ASSETS.md)。

## 從 Godot 4.1 參考案升級時要調整

1. **版本與 renderer**：參考案鎖定 4.1／Forward+。本機目前是 4.7.1；正式製作應固定同一個 4.7 patch 版本並檢查每一版 migration guide。Forward+ 適合桌面，Mobile 適合新款手機，Web／舊硬體則需 Compatibility，三者畫面不能假設完全一致。
2. **DOF 歸屬**：Godot 4 的景深與曝光屬於 `CameraAttributes`，不是 `Environment`。本專案把它掛在目前相機，避免非當前相機也套用。
3. **角色素材**：像素角色須用最近鄰取樣、billboard、透明裁切及一致的 pixels-per-unit。正式素材不應使用 FF6／歧路旅人角色或拆圖。
4. **輸入與移動**：參考案的腳本未型別化、鏡頭旋轉時會重複建立 tween，且減速沒有乘 `delta`。目前版本改為型別化 GDScript、相機狀態插值與 frame-rate independent acceleration。
5. **場景資料**：參考案把城堡幾乎全部序列化成單一巨大 `GridMap`。小型原型可接受；正式地圖應拆成區塊、可重用場景與資料資源，遠景再使用 MultiMesh、遮擋剔除與 LOD。
6. **後製預算**：Glow、SSAO、SSIL、景深、陰影與體積霧不能一次全部拉滿。透明 Sprite3D 也容易遇到排序、景深邊緣與陰影不一致，應在每個目標平台做 GPU profile。
7. **專案衛生**：不提交 `.godot/` 匯入快取與 `.DS_Store`；CI 至少執行 headless import／啟動測試，避免升級後場景或 shader 靜默失效。

後續 production 方向見 [docs/ROADMAP.md](docs/ROADMAP.md)。

村莊視覺素材包含 Blender 製作的砌石殘柱、生成式像素石板材質及道路兩側草叢；素材來源與尺寸見 [assets/generated/README.md](assets/generated/README.md)。Dream Loop 目標與工作截圖保存在本機 `.dream-loop/`（不提交）。

### 東行舊道與螢光森林

村莊東側舊路已開放，沿市場道路向東，穿過東側有成對路燈的路口即可自動出村，不需按 Space 或點互動，不需先完成主線。舊道西端返回村莊，北端通往螢光森林，森林南端返回舊道；小地圖金色出口與藍色事件記號提供方向。

- 舊道路標：扶正路標，獲得一瓶藥水。
- 驛路旅人：在森林西側岔路找回種子包裹，交還可得兩瓶藥水；先撿包裹再交談也有效。
- 月露草：森林東側採集一次，製成一瓶藥水。
- 螢光樹：北側空地可重複休息，恢復 HP / MP。

事件沿用 v3 存檔的 `flags` / `inventory`，舊存檔缺少事件旗標視為尚未進行，無需更動存檔結構。新地圖與事件建置在 `scripts/gameplay/outskirts.gd`，獎勵與完成狀態由 `GameState` 管理。沿用專案既有素材，螢光以程式生成。

快速試玩（停用事件自動存檔；F5 手動存檔仍有效）：

```bash
godot --path . -- --outskirts-preview
```

## 介面字體

一般介面、對話與場景招牌採用內嵌的思源黑體台灣繁中 Regular；地圖、裝備與戰鬥標題以思源宋體台灣繁中 SemiBold 點綴。標題 Label 使用共用 Theme 的 `TitleLabel` variation，對話正文加大行距。兩款字體採 SIL OFL 1.1，可免費商用，桌面與 Web 均不依賴系統字體；來源與完整授權見 `THIRD_PARTY_ASSETS.md`。像素美術維持 nearest-neighbor 過濾。

### 場景布料材質

床被、枕頭、地毯、織布、町屋門簾與星灣棚布共用 `scripts/gameplay/cloth_material.gd`：保留原有亞麻色彩貼圖及 nearest 像素取樣，加入快取的原創經緯織紋法線、低鏡面反射與高粗糙度。床被使用較細的垂墜網格及輕微皺褶；店舖棚布的米白條紋使用非自發光布料。角色服裝圖集不受此材質影響。可用 `godot --path . -- --interior-preview` 檢視床被與地毯；幾何回歸使用 `tests/interior_textiles_test.gd`。

### 壁爐與燈火

壁爐保留原有像素火焰圖集，增加兩層錯開節奏的側火舌、底部炭火、十顆循環上升並縮小熄滅的火星，以及連動的微幅暖光色彩變化。火舌根部固定在木柴上，火星在壁爐橫樑下消失；火星使用共享 MultiMesh，支援 Forward+ 與 Compatibility。路燈霧面玻璃的亮芯有小幅晃動，各燈以位置錯開閃動節奏。

房門互動：主角先走近門把，再播放獨立的抬臂、伸手握住、推拉與收手圖格；手伸出後門才轉動，門扇朝遠離主角的一側開啟。進出後回身走近關門、退回安全位置再恢復操作。八方向與四種現有裝備外觀都有對應圖格。

### 室內木作與接地

村莊與城內住宅的餐桌、椅凳、床架及櫃台使用低對比、依構件尺寸取樣的木作 shader，區分淺色桌面與深色支架，加入細微邊緣磨損。餐桌分為四塊拼板並增加桌裙；村莊地板保留 nearest 紋理與原有木板批次，加入輕微板間色差。桌椅、床底及城內櫃台使用不依賴 SSAO 的柔和地面陰影，兩種渲染器均可呈現，沿用原有碰撞範圍。

### 路面與草皮變化

`assets/generated/terrain/` 新增內建 imagegen 生成的碎石土路、破損石路與微枯草皮，完整提示詞記錄於該目錄的 README。廣場與城內主街保留主要石鋪面；村莊外圈、城內支路與庭園步道混合破石、泥土，東行舊道、螢光森林與商道改用碎石土路並播放泥地腳步聲。草皮以固定世界座標混合深淺、微枯和稀疏裸土區塊，草叢加入輕微色差；路線、碰撞與存檔格式不變。可用 `--outskirts-preview` 或 `--caravan-preview` 試看。

### 舊道野外戰鬥試玩區

從暮光村東出口前往東行舊道，離開橫向商道向南走，即可進入狩獵地。兩隻苔原狼會巡邏、追擊與近身撲打；高台上的月蝕術士會預告落點再施法。南側的暮翼蝙蝠會低空振翅巡邏，以較快速度追近後預告撲咬；生命 28、基礎攻擊 10，擊敗獲得 18 經驗與藥水。蝙蝠沿可通行地形移動，仍可用普攻與月影斬命中；既有存檔也會出現尚未擊敗的蝙蝠。西側石坡連接低地與 1.8 公尺高台，敵人會沿坡道追蹤；攻擊同時檢查高度與遮擋，不能隔崖命中。離開南側狩獵範圍會讓怪物返回原位並回復生命。主線守衛試煉維持原本流程。

- WASD 移動；J／1 普攻；K／2 月影斬（5 MP、3.5 秒冷卻）；Shift 朝移動／面向方向閃避；H／3 喝藥。Space 仍是互動。
- 畫面下方提供可點擊的戰鬥按鈕、冷卻與 HP／MP／經驗數值，手機可配合原有搖桿操作。開啟對話、地圖、裝備或視窗失焦時，野外戰鬥暫停。
- 普攻有短暫起手、前方範圍與命中打斷；月影斬攻擊周圍敵人。離開紅色預警範圍或使用閃避可躲開攻擊。
- 狼提供 18 經驗與一瓶藥水，術士提供 24 經驗與月苔材料；靠近掉落物會自動拾取。30 經驗升至 Lv.2，提升 HP／MP 上限、攻擊與防禦。月苔目前是收藏材料，尚無製作用途。
- 此版是三隻固定敵人的試玩區：擊敗後不會因切圖／讀檔重生；經驗、已擊敗敵人、未拾取掉落物均寫入 v4 存檔。v1～v3 舊存檔保留任務與物品，成長從 Lv.1 開始。倒下返回村口、回滿 HP／MP，保留已獲得經驗與物品。
- 直接試玩：`godot --path . -- --field-preview`。此入口從新執行階段的狀態開始，停在舊道狩獵地入口；不自動寫入一般玩家存檔，F5 仍可手動存檔。

實作：`field_combat.gd` 管理野外交戰與呈現，`field_navigation.gd` 取樣實際碰撞地面建立高度路徑，`field_terrain.gd` 建構坡道高台；持久化成長與獎勵由 `GameState` 管理。沿用專案既有角色、動作、材質與音效，未加入外部遊戲素材。

舊道狩獵地的戶外地形採用原創苔岩／風化砂岩貼圖、凹凸分層岩壁、16 列缺角石階、草土混合崖緣與上層土徑；坡腳碎石和低草保持中央行走／戰鬥路線清楚。石階視覺下方維持平滑坡道碰撞，避免角色逐級卡住。素材與最終生成提示詞見 `assets/generated/terrain/CLIFF_ASSETS.md`。

野外也支援自動戰鬥：在狩獵地入口或範圍內按 **B**／點「自動」開關，自動尋敵、沿坡道追擊、普攻與閃避，清場後走近拾取掉落物並停止。預設允許使用技能；「低血量喝藥」預設關閉，開啟後 HP 不超過 30% 時使用背包藥水。手動移動、點地圖尋路或出招會接手並關閉自動；選單、對話與視窗失焦期間暫停，離開地圖後需重新開啟。

### 怪物呈現打磨

狼、暮翼蝙蝠、月蝕術士與遺跡守衛共用 `enemy_presentation.gd`，在野外與守衛即時戰鬥中提供細微呼吸、蓄力壓身、出招伸展與短暫受擊色彩；蝙蝠振翅懸浮並在撲咬時降低高度，術士腳下法環會在蓄力時增亮，倒地後停止。名稱與細框血條依身高定位、維持深度遮擋並避免桌面景深模糊；守衛使用金色血條與調整後的身高比例。呈現只讀取戰鬥時鐘與狀態，不改變傷害、判定、碰撞或存檔資料。

### 灰燼墓窟地下城

暮光村東行至「東行舊道」，道路西側（路標附近）的雙火盆石拱門可按 **Space／Enter** 進入灰燼墓窟。沿墓窟前進，以 **J／1 普攻、K／2 月影斬、Shift 閃避、H 藥水、B 自動戰鬥** 擊敗五名守衛，再到北端血晶祭壇互動，首次淨化獲得藥水 ×3、月苔 ×2。南側出口互動可返回舊道；戰敗也會在墓窟外恢復。

原創地下城包含立體拱廊、破損石板、紅色垂旗、石棺浮雕、火盆、燭台及血晶祭壇，沿用現有敵人美術與即時戰鬥。地圖與 G 大地圖可導引至入口、出口與祭壇。地下城使用較寬的專用鏡頭並停用景深；離開後恢復原有鏡頭模式。

```bash
godot --path . -- --dungeon-preview
```

預覽不會自動寫入正常存檔。敵人擊敗、未拾取掉落物和一次性通關獎勵沿用 v4 的 `field_defeated`、`field_loot`、`flags`，不增加存檔欄位；舊檔自然視為尚未探索墓窟，各地圖只呈現其自己的戰利品。

戰鬥介面：即時戰鬥時右上角以三張對應頭像卡顯示隊員姓名、HP／MP 色條與數值；亮框及箭頭標示操作中角色，另顯示守護、危急與倒下狀態，右下角為圓形圖示操作：較大的普攻按鈕在內側，技能、閃避、換人與藥水沿四分之一圓弧排列，左側保留移動空間。圖示隨角色切換，冷卻顯示圓周進度與倒數。點「操作配置」或按 O，可預覽及調整按鈕大小、圓弧間距、水平／垂直位置、外圈順序與名稱顯示；開啟設定會暫停戰鬥，儲存或取消後回復原先暫停狀態。配置獨立儲存在 `user://battle_controls.cfg`，不變更冒險存檔。小地圖於戰鬥期間隱藏，結束後恢復。斬擊、霜星爆、治療與守護使用不同色彩的飛散粒子與擴散光環；特效跟隨戰鬥時鐘暫停，支援桌面與 Web 相容渲染。

### 月泉電影回憶示範

觸碰遺跡月泉會播放約 14 秒的水中月影、歸途回憶、村牆特寫與破碎月影演出，使用現有插圖與即時繪製水紋，無需影片。Space／Enter 或觸控可跳過並接到下一頁；自然播畢回到當頁對話，等待玩家繼續。

直接預覽：`godot --path . -- --story-preview`。演出由 `scripts/ui/dialogue_cinematic.gd` 負責，對話資料以 `cinematic: "moon_memory"` 啟用，不修改存檔或任務狀態。
