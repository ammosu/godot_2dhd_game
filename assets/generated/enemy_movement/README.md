# Enemy eight-direction locomotion

Original project-owned art generated with the built-in ImageGen tool on 2026-09-23; no new third-party material. PNG alpha and source pixels are preserved unchanged. Five species each have eight perspectives × three poses (idle, left step, right step; bats use level/up/down wings). Rows: south, southeast, east, northeast, north, northwest, west, southwest. The bat's corrected rear diagonal poses use `dusk_bat_rear.png` (three columns, northeast then northwest); its corresponding original rows are unused.

Run `python3 tools/art/inspect_enemy_movement.py` to measure alpha components into regions.json and regions.gd. Runtime shares scale across each direction's gait, anchors feet, uses camera-relative heading and a six-degree hysteresis margin, and caches textures. Movement cycles step A → neutral → step B → neutral. Original four-direction attack/hurt/defeat art remains in use; the ash warden retains its existing frontal combat poses. Movement facing does not change combat targeting or save data.
