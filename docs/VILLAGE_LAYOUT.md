# 村莊比例與照明改版

使用者已選擇更貼近原目標圖，授權調整房屋尺度、廣場比例與照明。
本輪保留既有原創角色、月燈設計及八屋用途，不新增玩法。

## 實作

- 八屋外觀 X／Z 放大 15%、Y 放大 8%，使建築更寬、立面在畫面中更有份量。
  外觀根節點共同變換，StaticBody 保持單位縮放，碰撞盒以明確尺寸重建；
  入口位置及返村點使用 HouseCatalog 的同一尺度資料。室內尺寸不變。
- 中央廣場由 10.5 × 8.5 公尺改為 7.8 × 8.0 公尺，面積減少約 30%。
  第一版深度 6.8 留下細窄草縫，因此恢復足夠深度與 MarketRoad／GateRoad 相交。
  鋪面 shader 及植被排除區繼續讀取實際幾何，不另存一套邊界。
- 東南小屋中心 Z 由 11 改為 12.3，避免返村點落入放大後的陶匠小屋。
  房屋 ID 與任務／室內存檔識別不變。
- 小地圖住宅矩形改讀 HouseCatalog 的位置、旋轉與碰撞尺寸，廣場同步縮小，
  不再保留改版前的八個固定房屋矩形。
- 路燈保留既有節點數，玻璃提高中心自發光，局部光使用能量 5.5、
  範圍 5.0、衰減 1.25，讓暖色光池延伸到石路與周邊花草。

## 舊存檔與通行

存檔格式沒有變更。讀取村莊舊座標時，若落入新版住宅碰撞範圍（含玩家半徑餘量），
改在該屋門外落地；其他村莊座標及室內／遺跡座標不變，不直接覆寫存檔。
`house_interior_test.gd` 逐屋驗證原邊界座標、返村點、實際載入修正及進出屋流程。
初次整體回歸 53／54 暴露東南小屋與陶匠小屋的通行衝突；移屋後八屋專項通過。
`garden_art_test.gd` 新增廣場與東西道路相交檢查，防止狹窄草縫回歸。

修正後完整清單 54／54 通過，日誌 `wanderlight-assets-t137x8lt`。
小地圖同步後，Forward+／Compatibility 完整主線及 Web release 匯出再次通過，
日誌無 `ERROR:`／`SCRIPT ERROR:`／退出洩漏，`git diff --check` 通過。
兩種 renderer 的村莊實景已檢視；這不是所有鏡頭位置的完整人工遊玩驗收。

## 視覺結果與限制

沿用 `.dream-loop/target.png`，沒有用改寫目標圖降低驗收標準。
兩輪獨立評分 7.4 → 7.7（改版前 7.1）；第二輪構圖 2.6、光照 2.1、材質 2.2、細節 0.8。
建築包圍感、道路銜接與暖光改善。尚未達到 8 分門檻：下一個主要差距是
石材立體感、植被高低輪廓與前景層次，不應再靠微調廣場尺寸追分。
這是村莊改版紀錄，不代表全部資產、連續動畫或混音已完成。
