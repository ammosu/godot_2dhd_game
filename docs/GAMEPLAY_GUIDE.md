# 序章〈熄滅的月燈〉遊玩指南

本指南將 [故事聖經](STORY_BIBLE.md) 對應到目前可玩的操作。序章由旅人單人探索，諾亞與艾爾在試煉加入；古道甦醒是序章結尾，後續旅程尚未開放。

## 探索與互動

WASD／方向鍵移動，Q／E 旋轉鏡頭，R／F 縮放。移動方向會隨鏡頭旋轉。靠近角色或物件，看畫面下方提示，再按 Space／Enter 互動；同樣按鍵繼續對話。手機用左側搖桿與右側互動鍵，對話時點畫面繼續。

金色驚嘆號是主線目標，青藍色是可選內容。小地圖顯示出口與主線目標，左上提示會依所在區域更新。閱讀對話、戰鬥或換裝期間不能觸發另一個世界互動。

| 故事階段 | 玩家操作 | 完成後的結果 |
| --- | --- | --- |
| 不再照向村莊的月光 | 調查廣場中央月燈，聆聽低語 | 理解月燈將熄；不強制閱讀才可接任務 |
| 村莊中的三種立場 | 可先找露米、諾亞，再與月燈旁艾爾交談至最後一頁 | 接受任務，月印開啟北門 |
| 被抹去的道路 | 直接穿過北門；在遺跡西側閱讀石碑、東側觸碰月泉 | 石碑留下線索旗標；月泉恢復 HP／MP 並提供操作教學，兩者皆非必做 |
| 守衛的試煉 | 沿中央月紋石路向北，與守衛交談至最後一頁 | 諾亞與艾爾加入 3 對 3 戰鬥 |
| 碎片的選擇 | 擊敗三名敵人，結束戰鬥並閱讀守衛告別 | 自動獲得月光碎片，不必再撿取展示模型 |
| 最後一盞路燈 | 穿過遺跡南門回村，與艾爾交談至交付完成 | 碎片融入月燈、恢復 HP／MP、獲得三瓶藥水，演出古道與霧中甦醒者 |

石碑可以跳過，守衛仍會說明碎片能救村並喚醒古道。讀過石碑時，守衛與結尾會回應被抹去名字的紋章。這些是額外資訊，不影響任務獎勵或結局。

## 試煉操作

先替每位存活同伴選指令與目標，按「安排」後可繼續安排下一位；點角色摘要可修改，全部安排好後按「開始回合」。桌面可按 1～6 選指令，Tab／Enter 切換並啟用按鈕；手機直接點選。雙方依金色速度條的數值由高到低交錯出手，同速採固定順序，倒地者跳過。演出期間無法改指令或站位。

站位列可切換「自動戰鬥」：開啟後會重新安排全隊動作，優先治療／守護低血量同伴，選擇範圍法術或攻擊，並連續開始回合。自動模式不使用藥水、不更換站位；可隨時關閉，正在執行的回合結束後恢復手動。勝敗後自動停止，下一場預設關閉。

安排階段可把友方角色拖到同伴身上交換前、中、後排，整隊每回合限一次；前／中／後排按鈕提供相同操作。角色旁的綠色 HP、藍色 MP 條會即時更新。普通近戰只能命中敵方最前方存活排，長槍與月影斬可多打一排，法術可越過前排。敵方遵守相同規則；前排倒地後，後方會暴露。防禦與守護從角色出手時生效，到下一回合開始出手前清除。

| 角色 | 技能與用途 |
| --- | --- |
| 旅人 | 月影斬消耗 5 MP，集中打擊一名敵人 |
| 諾亞 | 守護同伴消耗 4 MP，選另一名存活友方，承受傷害減半至諾亞下次行動或倒下 |
| 艾爾 | 月光彈消耗 5 MP；霜星爆消耗 8 MP，選中央敵人可波及三人；月泉療癒消耗 6 MP，恢復存活友方最多 30 HP |
| 全員 | 普通攻擊、防禦不耗 MP；藥水使用共享庫存，恢復目前行動者 35 HP |

防禦與守護不疊加；療癒不能復活。旅人倒下仍可由同伴贏得試煉，勝利後旅人以至少 1 HP 起身。全隊倒下才敗北：返回村莊並恢復旅人 HP／MP，任務保持進行中，可再次穿過北門挑戰；已消耗藥水不返還。沒有藥水時仍能使用普通攻擊、防禦與艾爾的療癒。

## 準備、存檔與可選探索

探索時按 I（手機右上「裝備」）調整三人的武器與防具，確認穿戴才生效；Esc 取消未確認的試穿。F5 儲存、F9 讀取，手機用右上存讀檔鍵。戰鬥與對話期間不存讀檔。試煉勝利與任務交付會自動存檔；想保留更早的位置與進度，請留意自動存檔會更新同一存檔槽。

八棟住宅都能靠門口互動進入、從室內南側出口互動離開。各屋主題家具可調查，補充道路紋樣、月相偏移、舊陶器、旅人與草藥路線的故事；床鋪不恢復 HP／MP。花園幼苗在月燈復燃前後有不同描述。住宅探索不影響接任務、試煉或結局。

結尾後可找艾爾、諾亞、露米交談，重新調查月燈與住宅，理解拯救村莊後仍待面對的責任。
