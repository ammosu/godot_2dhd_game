# 八屋返村視角檢查

## 證據範圍

來源：`tests/village_entrance_capture.gd` 產生的
`/tmp/wanderlight-billboard.Wl90tA`，共 32 張 1280×720 畫面。
每屋在實際返村位置拍攝 45／225 度，Forward+ 與 Compatibility 各一套。
本次逐張看完全部 32 張；不是只檢查檔案存在或程式成功標記。
畫面包含門前植被淨空、花園圍欄移位及 billboard 平面遮擋修正。
本次檢查前確認目前遮擋程式仍包含拍攝時的修正，後續只增加音訊試聽工具，
未修改場景。未為看圖特別隱藏房屋、樹木、HUD 或停用遮擋控制器。

## 已關閉與未關閉項目

此固定視角集合的入口角色遮擋與提示可讀性檢查完成，未發現新增異常。
不再將這 32 張記為「僅抽查」；較早驗收文件中的抽查記錄保留作歷程。

尚未證明：連續移動／鏡頭切換的視覺穩定性、所有縮放與視窗尺寸、全部
任意位置，或瀏覽器實際渲染。切除後低基座仍顯示碰撞範圍，這不是可參觀
室內的透視圖。室內流程與家具由另外的測試和畫面檢查覆蓋。

美術差異仍在：Compatibility 沒有景深，投影邊界較硬，植物與窗光對比
較高；部分邊界地帶仍空曠，道路、屋瓦與角色的像素尺度不完全一致。
這份可讀性檢查不能替代原目標圖的構圖／材質／光照驗收，也未提高前次
7.8／10 的目標相似度評分。
