# 月紋門與村界石牆

月紋門框與村莊邊界牆使用世界尺度的錯縫砌石 shader：石塊約 58 × 29 cm，取樣每公尺 64 格，帶低幅度逐塊色差及細石縫。共用原創切石貼圖，不因牆長拉伸紋理；側面與頂面亦有材質。幾何尺寸、邊界碰撞、入口觸發體及傳送規則不變。

門扉接入既有原創木紋、金屬橫條使用原創舊銅材質；兩面均有橫條與中央直條。村莊門的月印、核心、燈與牌匾改朝村內，遺跡返回門則維持朝遺跡內側。原本被門板擋住的村內月印可見後，降低其發光強度以保留輪廓。任務開門動畫與封印淡出沿用原節點。

`tests/gate_art_test.gd` 覆蓋雙面細節、四段牆面材質、碰撞大小、門印朝向、開門角度與封印淡出。雙渲染器實機近景另行核對。這不代表城牆輪廓、門框整體造型或全村美術已完成；目前未增加新雕刻或改建村界。
