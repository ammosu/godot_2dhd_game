# HD-2D 開發路線

## 目前優先順序：先完成素材，再擴充遊戲性

以目前序章的暮光村、北境遺跡與戰鬥為素材驗收範圍；整體資源尚未完成。

角色演出現況以此為準：六名戰鬥角色已具備待機、蓄力、攻擊／釋放及收招關鍵姿勢，並已接入回合演出；下方「其他角色待補」是較早製作歷程，不代表目前缺少這些圖集。最新六角色四姿勢並排實景檢查未見明顯裁切或接地異常，旅人／施法者時序回歸通過。仍不是完整逐格動畫，也未取代探索動作與各種技能全程驗收。

八屋室內用途家具已分化：織布架、育苗工作架、月相紀錄架、晾陶架、布料櫃、旅人裝備架、草藥架與藏書閱讀櫃。原有格局／碰撞／存讀檔不變，並不代表八種獨立房型或新增製作玩法。正反視角比較與製作記錄見 `docs/HOUSE_VISUAL_REVIEW.md`；下一步收斂行走／側向視角、材質一致性與整體資產驗收，避免持續堆疊裝飾取代驗收。

整體技術回歸已有 54 項清單（含 8 項實際 GPU 測試、字型覆蓋、地圖資源快取、家具遮擋、八屋行走及新版殘柱）完整重跑通過；目前完成證據與下一道驗收門檻集中於 `docs/ASSET_ACCEPTANCE.md`。下方保留各輪製作歷程，不以其中的局部通過取代整體驗收。

多人需求已確認為多名隊友對多名敵人：主線接入 3 對 3 隊伍回合制、單體月光彈、範圍霜星爆與敵方施法。選技能／目標後預覽範圍和命中名單，確認後在爆發時扣 MP、結算傷害；跳過倒地角色，全隊倒下才敗北。GameState 持有獨立 PartyBattle 狀態並回寫旅人與道具，UI 只負責輸入和演出。援軍每場恢復，尚無永久隊伍編成。諾亞／長老專用四姿勢已完成；旅人月影斬、諾亞守護、長老單體／範圍魔法與治療已分工，指令依角色切換。更豐富的技能專用音效、逐格動畫及多場遭遇平衡仍待擴充。

苔背狼與月蝕術士各四個原創姿勢（探索正面、戰鬥待機、攻擊、受擊）已接入守衛試煉的敵方隊伍，另保留獨立 `enemy_art_gallery.tscn` 預覽。這些是關鍵姿勢而非完整逐格動畫，尚未新增獨立野外遭遇或掉落表。

月燈後續修正已通過局部 Dream Loop 8.1/10：分離廣場照明與燈架補光、限制燈心發光、降低橘色銅材並補入石座風化。模型測試、Forward+／Compatibility 主線測試及 Web 匯出通過。先前 7.4/10 與過曝記錄如下保留作為歷程，已由此輪取代；屋頂比例、金屬邊緣高光與石塊接縫仍有精修空間，不代表全村素材完成。

中央月燈已接入四網格、2,272 三角形的原創 Blender 模型與銅／石材貼圖，並修正 glTF 頂點色匯出。模型測試、雙渲染器主線測試與 Web 匯出通過；2026-09-20 Dream Loop 局部比對為 7.4/10，未達美術驗收門檻。銅色過橘、石座過於乾淨，暫停反覆小幅調色，待確認美術方向。後續已查明並修正燈心缺少相乘發光貼圖的問題，Forward+／Compatibility 實機皆確認會發光；恢復狀態的高光過曝仍待改善。近景 Forward+ 幀時間中位數 3.871 ms、Compatibility 10.287 ms，僅代表該測試視角，不是全遊戲效能驗收。

室內布料已換成原創亞麻織紋：被子採薄布面沿床緣垂下，枕頭改為弧面，地毯加包邊與短流蘇；書本封面共用染色織物。家具碰撞與通道不變，仍不代表所有室內美術已完成。

Compatibility 室內偏亮紫背景已修正：使用專屬低層畫布背景，保留泛光與房間燈光，離屋後恢復原戶外模式。雙渲染器實際像素與視窗縮放測試通過；仍不代表所有室內材質和光照已達整體美術驗收。診斷見 `docs/INTERIOR_BACKDROP.md`。

依使用者指示，本階段先忽略行動裝置：不以手機效能、觸控操作或跨手機測試作為目前完成門檻。以桌面版及桌面瀏覽器為主，保留既有觸控支援；Compatibility 回歸與 Web 匯出檢查仍照常執行。行動裝置最佳化延後，不阻擋目前素材與後續遊戲性工作。
