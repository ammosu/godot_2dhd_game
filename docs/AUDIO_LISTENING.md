# 音訊試聽驗收

技術檢查與主觀驗收分開記錄。PCM 完整、沒有滿刻度樣本、播放路由正確，
不代表配樂適合、循環聽不出接點或混音已獲使用者接受。

## 可重現的桌面試聽

先建立輸出目錄，再執行：

```bash
godot --path . --rendering-method gl_compatibility --script tests/audio_mix_audition.gd -- --capture-dir=/existing/output/directory
```

需實際桌面音訊裝置，不能使用 `--headless` 或 `--mute-audio`。約需 135 秒，
會播放声音。此工具直接錄製 Godot Master 匯流排，使用正常 Music、Ambience、
SFX 播放器與混音量，暫時把 Master 設為預設 80%／解除靜音；不寫入偏好檔，
結束時恢復原執行期音量並移除錄音效果。不建立世界、不讀寫玩家存檔。

錄音取自 Master 效果鏈，不是系統喇叭輸出的迴路錄音；不要把檔案振幅
視為已包含最終 Master 推桿、系統或播放器音量。試聽時先用較低音量。
每個 WAV 約 33 秒，未正規化或後製。錄音必須有訊號、至少 32 秒且沒有
滿刻度峰值，才輸出 `AUDIO_MIX_AUDITION_PASS`；這不是聽感通過標記。

| 檔案 | 情境與音效時間（約） | 特別注意 |
| --- | --- | --- |
| `village.wav` | 村莊配樂＋環境音；2–3 秒石地腳步；4–4.5 秒對話提示 | 24 秒配樂循環、約 12／24 秒環境音接續；對話提示是否刺耳 |
| `ruins.wav` | 遺跡配樂＋環境音；2–3 秒土地腳步；5 秒對話提示 | 30 秒配樂循環；氛圍是否過於單調或壓迫 |
| `battle.wav` | 戰鬥配樂；2 秒月影斬、4 秒槍擊、6 秒霜星爆、6.5 秒三個同時霜擊、9 秒守護、11 秒治療、13 秒月光彈、15 秒爪擊 | 17 秒附近配樂循環；魔法辨識、三重命中是否過響、是否掩蓋配樂 |
| `house.wav` | 村莊配樂＋室內環境音；2–3 秒木地腳步；5 秒對話提示 | 腳步材質差異、室內環境音與配樂是否互相干擾 |

這是人工安排提示音的混音試聽，不代表實際技能結算時序或全部技能組合。
開始的淡入與結尾截斷不是循環接點；試聽播放器自身不會無縫循環整段。
實際音量也受作業系統、耳機及播放器影響。

## 使用者需確認的項目

- 四種情境的音樂風格是否可接受；若不合適，指出情境與希望的方向。
- 對話、腳步與技能音效是否清楚、不刺耳，音量主次是否自然。
- 上表指定的原曲循環附近，是否聽見突然斷裂、爆音或不自然的重複。

尚未取得主觀聽感確認。桌面錄音不能證明 Web Sample 排程沒有間隙，
也不能取代不同瀏覽器、切圖負載下或長時間的音訊驗收。
