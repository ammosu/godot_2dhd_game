# 石路立體感試作：未採用

基準是房屋／廣場改版後的 7.7 分村莊，目標仍是原 `.dream-loop/target.png`。
本輪沒有把失敗試作留在遊戲中，正式鋪面仍為 `village_paving_v2.png`。

## 試作與判定

1. **亮度推算法線**：對原貼圖的亮暗作四向差分，推算淺凹凸，世界座標維持跨道路一致。
   獨立評審 7.6 分，主要增加暗石縫及細碎對比，沒有可信厚度；已撤回 shader 修改。
2. **四種 Blender 倒角薄石塊**：外部下載未獲授權、FAL_KEY 不存在，依 dream-loop
   改用獨立背景 Blender，不碰使用者正在開啟的場景。先試既有原創石灰岩貼圖，
   再用原鋪面貼圖的石面 UV 區域；四個 MultiMesh 批次、變動列寬與石塊長度。
   頂面保持 0.006 m、碰撞不變，泥層降低以露出倒角。
   獨立評審 6.9 分：鋸齒路緣、長直暗縫、裸露泥地及石中套石的尺度混淆更明顯。
   已撤回整合、泥層與地面裁切修改。

試作模型、貼圖副本、Blender 來源、GDScript 及雙 renderer 圖片移到
`.dream-loop/rejected-paving/`，未刪除、未提交，不由遊戲載入。
原創貼圖與原石路均保留；沒有新增第三方素材。

還原後重跑花草／鋪面專項、Forward+ 與 Compatibility 完整主線、Web release
匯出皆通過，未見 Godot 錯誤或退出洩漏。兩渲染器重新輸出村莊圖，
已看圖確認 Forward+ 恢復原本連續石路；本輪未重跑完整 54 項清單。

## 後續原則

不能把增加幾何或法線本身當作品質改善。下一次若重做實體鋪面，需先確保
連續覆蓋原道路邊界、緊密且不規則的接縫，以及專用單石 UV，不能再用
整塊石頭中心取樣法代替正確貼圖。這兩次試作不足以宣稱石路材質驗收完成。
依 dream-loop 停滯規則停止這條重做路線，保留較好的基準，待美術取捨確認。
