# 星灣城公共空間配置

先以現有道路與房屋的遊戲地圖為參考，使用內建 image_gen 產生城市配置圖，再依實際場景座標校準。概念圖是配置方向，並非精確測繪；遊戲地圖與碰撞測試決定最終位置。

| 概念 | 實作中心 (X, Z) | 公共空間 |
| --- | --- | --- |
| A 月儀庭 | -9, -9 | 銅製天文環、月晶石、雙側花壇、環形步道 |
| B 樹蔭庭園 | -18, 10 | 老橡樹、樹穴花壇、兩張長椅、連接市集的小徑 |
| C 水岸涼亭 | 8, 0 | 六角灰瓦木亭、亭內長椅、池岸花草 |

另外在舊城北側、工坊街與南岸設置三處街角植栽。保留不規則城界、原有五條彎曲街道、26 棟房屋及八棟日式外觀；新增五條窄步道將公共空間接回街網。散植花草避開道路、屋門前場、池水及涼亭。

場景、區域地圖、通行測試共用 `city_civic.gd` 的座標資料。非住宅地標為程式原創幾何，重用已有材質及植物，不新增第三方素材。概念圖只用於文件，不匯入遊戲資源。

實景：[月儀庭](starbay-moon-ingame.png)、[樹蔭庭園](starbay-tree-ingame.png)、[水岸涼亭](starbay-pavilion-ingame.png)。
