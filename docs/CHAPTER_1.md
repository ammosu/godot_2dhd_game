# 第一章〈醒來的古道〉故事企劃

## 文件定位

本文件是序章〈熄滅的月燈〉之後的第一章主線企劃，承接 [故事聖經](STORY_BIBLE.md) 的世界真相、角色動機與資訊揭露界線。第一章**只使用現有地圖**：暮光村、東行舊道、風丘商道、星灣城、灰燼墓窟三層、螢光森林、苔階山徑、風切峽道與月冠高地。

目前狀態：**第一版已可遊玩**（2026-10-04）。九個劇情節點、同行隊友、鐘紋封門、四件關鍵道具、提燈人結尾與存檔 v10 已實作；實作方式與尚未完成的部分見文末〈實作狀態〉。

## 用詞原則

沿用故事聖經〈兩層世界觀〉：主線台詞只用霧、月光、月燈、碎片、鐘、門等簡單詞；引路人、引路之環、燼冠的完整歷史等細節放在可選調查與閒聊中，主線不逐一解釋。

## 本章命題

> 燈亮起時，路也會醒來。

序章問的是「該不該點亮月燈」；第一章問的是「點亮之後，醒來的是什麼」，以及「沒有結界的地方，人們怎麼面對夜霧」。

- 暮光村以**牆**面對夜霧：封閉道路、集中月光，換來安全。
- 星灣城以**鐘聲**面對夜霧：保持道路開放，讓迷途者循聲回來。
- 燼冠以**王座**面對夜霧：把月光收為己有，最後連自己都被灰燼吞沒。

旅人在三種答案之間前進，第一章結束時仍不必選邊，但要明白：月光的用法，本身就是一種選擇。

## 登場角色

### 旅人
玩家在選角時決定職業、性別與配色。在霧中醒來、失去記憶（見故事聖經〈旅人〉）。第一章持續聽見古道的低語，並在月冠高地被提燈人認出；「十二年前北門外的商隊孩子」這個真相仍不揭露。

### 守門人・諾亞（同行）
序章後第一次離開村門。他以「替別人開路」取代「替村莊守門」，但仍懷疑自己是否背叛長老。能力沿用「守護同伴」。

### 鐘守・希雅（新角色，同行）
- **身分**：星灣城守鐘人之家的學徒，負責夜霧來時敲響古鐘。
- **外觀方向**：深藍短斗篷、銅色鐘槌、腰間掛小型手搖鈴；髮色與旅人、諾亞明顯區隔（例如深栗色短髮）。需新增原創美術。
- **戰鬥定位**：中距離支援。鐘聲可短暫緩速敵人、清除同伴的減益；基礎攻擊為鐘槌近身敲擊。實作時沿用現有技能框架（消耗 MP、冷卻時間）。
- **性格**：開朗、務實，相信「只要鐘聲傳得到，就沒有人真的走丟」。對暮光村的封閉做法不以為然，但不帶敵意。
- **弧線**：一開始把暮光村視為「關起門的鄰居」；在墓窟看見燼冠的下場後，理解暮光村的恐懼也有來由。

### 長老・艾爾
留守暮光村維持月燈。第一章只在第一幕與章末（書信或返村對話，實作時決定）出現。

### 村童・露米
第一幕的情感錨點：發現影子改向東延伸，並託旅人把一件小東西帶給星灣城（例如寫給從未見過的「外面的人」的信）。

### 燼冠與典獄長維爾莫（Boss）
燼冠是古代想把月光留給自己的那群守路人的領頭，最後被灰燼吞沒，只剩空王座與低語，不直接參戰。實際的 Boss 是現有的「燼冠典獄長・維爾莫」：燼冠的侍從，把最後一點月光封進胸口紅晶，只記得「不准任何人帶走光」。擊敗他後取得被灰燼汙染的第二枚碎片。

### 提燈人（霧中甦醒者）
數百年來在夜霧中提燈、替迷途者引路的存在。不是敵人，也不完全可信：他在乎的是「路」，不是任何一座村莊。第一章只揭露其存在與目的，不揭露身分與過去。

## 一句話摘要

月燈亮起後，光路轉向東方。主角帶著露米寫給「外面的人」的信，與諾亞沿光路東行；在不關城門、靠鐘聲帶人回家的星灣城認識修鐘的希雅並取得鐘槌，打開墓窟、擊敗典獄長維爾莫取得被灰燼覆蓋的第二塊碎片，再登上月冠高地讓碎片重新發光，最後遇見說出「你終於回來了」的提燈人。

## 分幕大綱

### 第一幕：燈亮之後（暮光村）

**事件**
1. 月燈復燃的隔天夜晚。廣場的環形光路缺口不再朝北，而是轉向東方的舊道。
2. 露米發現月燈旁的影子全部改向東延伸，並託旅人帶一封信「給外面的人」。
3. 旅人與艾爾對質灼痕。艾爾承認：「這盞燈……是從一個更大的東西上拆下來的。」但仍不說出拆下的經過。
4. 諾亞在東口等候，主動同行。

**關鍵台詞**
- 艾爾：「我守著這盞燈，是為了今晚。至於它原本屬於哪裡……等你回來，我再說。」
- 諾亞：「門我守了很多年。這一次，換我替你開路。」

**玩法**：主線對話；諾亞加入隊伍；任務目標改為「沿光路東行」。

### 第二幕：東行舊道

**事件**
1. 舊道上的路燈一夜之間自行亮起幾盞，亮起的方向一路向東。
2. 驛路旅人（現有 NPC）說：燈亮了之後，霧裡的野獸反而變多，像是被光吸引過來。
3. 光路延伸到灰燼墓窟入口，入口被刻有鐘紋的封門擋住，無法進入。
4. 石縫中有與星灣城鐘樓相同的鐘紋，暗示鑰匙在城裡。

**玩法**：沿用現有支線（路標、包裹、月露草）；調查鐘紋封門，任務指向星灣城。

### 第三幕：不築牆的城（風丘商道 → 星灣城）

**事件**
1. 商道上的旅人說，星灣城從沒有結界，但夜霧來時，鐘聲會把人帶回城裡。
2. 在守鐘人之家遇見希雅。她正在修一口裂開的古鐘，裂縫形狀正是缺口環。
3. 書屋的古城街巷圖保留完整紋章與「引路之環」四字，並標出暮光村與星灣城曾是同一條古道上的兩個驛站。
4. 露米的信交給城內居民後，對方回信給暮光村（為第二章埋下兩地往來的伏筆）。
5. 希雅帶著鐘槌同行：「鐘紋封門只認得鐘聲。」

**關鍵台詞**
- 希雅：「牆能擋住霧，也能擋住回家的人。我們選了會被聽見的那一邊。」

**玩法**：城內主線對話與調查；希雅加入；取得「古鐘槌」（開啟墓窟封門的關鍵道具）。

### 第四幕：燼冠（灰燼墓窟 B1 → B2 → 燼冠王座）

**事件**
1. 希雅敲響鐘槌，封門隨鐘聲開啟。
2. B1 燭火迴廊：壁畫描繪引路人分裂成兩派，一派主張「光屬於路」，另一派主張「光屬於守住它的人」。
3. B2 沉灰牢廊：被灰燼封住的人影，是當年跟隨燼冠、最後失去方向的引路人。
4. 燼冠王座：空王座傳出燼冠的低語（序章月蝕術士的原型）：「光若不歸我所有，就會被別人奪走。」守在王座前的典獄長維爾莫發動戰鬥。
5. 擊敗維爾莫後取得**燼色碎片**：它是引路之環的第二枚碎片，但被灰燼汙染，發不出光。

**關鍵台詞**
- 燼冠（低語）：「我只是比你們早一步明白：分出去的光，永遠不會回來。」
- 諾亞（戰後）：「他守住了光……卻把自己關在裡面。」

**玩法**：使用現有地城三層與維爾莫 Boss 戰；戰後取得燼色碎片（新道具鍵）。

### 第五幕：霧的高處（螢光森林 → 苔階山徑 → 風切峽道 → 月冠高地）

**事件**
1. 希雅推測：只有在最接近月亮的地方，碎片才能洗去灰燼。
2. 螢光森林的月露草朝山上生長（呼應序章花園小屋的伏筆）。
3. 登山途中霧越來越濃；野外戰鬥強度提升。
4. 風切峽道的營火對話：諾亞說出自己的轉變。

**關鍵台詞**
- 諾亞：「我一直以為門是用來擋人的。現在才明白，有些門，是為了讓人回家而開。」

**玩法**：山路探索與野外戰鬥；兩名同伴的營火對話。

### 第六幕：提燈人（月冠高地・眺望點）

**事件（章末過場，使用本輪的過場系統）**
1. 眺望點的月光下，燼色碎片的灰燼剝落，重新發出銀光。
2. 霧中走出一名提燈的身影：提燈人。祂說，古道醒來時，祂也跟著醒了。
3. 提燈人要旅人把碎片帶回「它原本的地方」，但不說那是哪裡。
4. 提燈人看著旅人：「你終於回來了。」旅人不記得見過祂。
5. 鏡頭拉遠：雲海中浮現數處微弱燈點，代表其他碎片與失落聚落。
6. 標題卡：第一章〈醒來的古道〉完。

**關鍵台詞**
- 提燈人：「燈亮了，路醒了。接下來，就看你要把光帶往哪裡。」
- 提燈人：「……你終於回來了。」

## 資訊揭露界線

### 第一章必須讓玩家理解
- 月燈來自引路之環，艾爾知道這件事。
- 世界上有不同面對夜霧的方式，暮光村的做法不是唯一的答案。
- 引路人曾經分裂，燼冠代表「占有月光」的一派。
- 碎片不只一枚，而且會回應月光與「願意承擔道路的人」。
- 霧中甦醒者（提燈人）存在，並認識旅人。

### 第一章只暗示、不回答
- 旅人與提燈人的關係。
- 暮光村祖先拆下引路之環碎片的完整經過。
- 其他碎片的位置與數量。
- 提燈人究竟想把碎片帶回哪裡。

## 過場系統（本輪已實作）

- `scripts/gameplay/cutscene_player.gd`：以資料驅動的過場播放器，負責地圖切換、攝影機、演員走位、字幕、淡入淡出、音樂與跳過。
- `scripts/ui/cutscene_overlay.gd`：黑邊、字幕、標題卡與跳過提示。
- `scripts/story/opening_cutscene.gd`：遊戲開場影片的鏡頭資料，可作為撰寫章節過場的範例。
- 新增 `GameState.Mode.CUTSCENE`，播放期間鎖定探索輸入；主角即為玩家所選角色，不需另外準備美術。
